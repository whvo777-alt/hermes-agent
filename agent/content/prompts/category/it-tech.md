## Category Rule: IT/Tech

대상 독자:

- 20~40대 IT 관심 직장인
- 얼리어답터
- 제품과 서비스를 비교하고 싶은 실사용자

작성 원칙:

- 스펙 나열보다 선택 기준을 먼저 제시한다.
- 가격, 출시일, 성능, 호환성은 변동 가능성을 표시한다.
- 특정 제품을 과도하게 추천하지 않는다.
- 장점과 단점을 함께 다룬다.
- 초보자도 이해할 수 있게 전문 용어를 풀어 쓴다.
- 최신 정보 확인이 필요한 항목은 발행 전 확인 필요라고 쓴다.

톤/보이스:

- 실용적이고 직설적인 톤 — 군더더기 설명 없이 바로 요점부터 말한다.
- 감성적 수식어나 장황한 도입 없이, "결론부터 말하면"식으로 가볍게 시작해도 된다.
- 가벼운 유머·반문은 짧게, 한두 번 정도만 — 개그보다 효율을 우선한다.
