## Platform Rule: Tistory Blog

티스토리 블로그는 Google SEO와 AdSense 친화성을 함께 고려한다.

핵심 방향:

- 검색 유입형 정보 글을 작성한다.
- H1, H2, H3 계층 구조를 명확히 유지한다.
- 도입부에서 검색 의도와 독자 문제를 빠르게 설명한다.
- 체류 시간을 높일 수 있도록 요약, 표, 체크리스트를 배치한다.
- AdSense 정책에 불리한 과장, 선정성, 클릭 유도 표현을 피한다.
- 네이버식 이웃 CTA나 친목형 문체를 쓰지 않는다.

필수 구조:

- H1 제목으로 시작한다.
- H1(#)은 글 맨 앞 제목 하나만 쓰고, 본문 중간에는 쓰지 않는다.
- H1 다음에 이미지 자리 1개, 그다음 요약 문단 2개, 그다음 ## 목차 순서로 쓴다.
- ## 목차 H2를 두고 바로 다음 줄부터 번호 목록(1. 2. 3.)으로 H2 제목을 그대로 나열한다. 항목 수와 H2 개수를 정확히 일치시킨다. "자주 묻는 질문"도 포함한다.
- H2(##)를 5~6개 쓴다. 마지막 H2는 "자주 묻는 질문"으로 한다.
- H2 제목에는 번호를 쓰지 않는다. 변환기가 번호를 자동으로 붙인다.
- 필요한 경우 H3 하위 섹션을 둔다.
- 실전 체크리스트를 포함한다.
- 마지막 H2 바로 앞에 ### 참고할 수 있는 공식 자료 H3를 두고, Research에 제공된 정부·공공기관 공식 페이지 3~4곳을 기관명과 자료 이름으로 목록에 적는다. URL은 적지 않는다.
- 숫자 예시는 가정을 문장으로 먼저 밝힌다. 수수료나 세금이 있으면 이를 반영한 결과 금액을 적는다.
- 내부링크 후보는 본문 섹션으로 쓰지 말고, 문서 맨 끝 `---META---` 아래 제작용 메모로 기록한다.
- 내부링크 후보는 실제 URL이 아니라 제목 후보만 쓴다.
- 대표 이미지 ALT 텍스트와 캡션 제안도 본문이 아닌 `---META---` 아래 제작용 메모로 기록한다.
- [모바일 최적화 체크] 와 [애드센스 승인 체크] 는 본문에 쓰지 말고 `---META---` 아래 제작용 메모로 기록한다.
- `---META---` 아래 첫 항목은 반드시 "내부링크 후보"로 시작하고, 그 뒤에 대표 이미지 정보, 모바일 최적화 체크, 애드센스 승인 체크를 차례로 적는다.

표시 규칙:

- 각 대단원에서 독자가 꼭 기억할 문장 안의 핵심 어구 하나를 `==문장==`으로 감싼다. 문단 전체를 감싸지 않는다.
- 반드시 지켜야 할 결론은 한 문장으로 끝나는 한 줄을 `**핵심: ...**`로 쓴다.
- 놓치면 손해 보는 내용은 한 문장으로 끝나는 한 줄을 `**주의: ...**`로 쓴다.
- 글 마지막에는 한 줄짜리 `**면책: ...**`을 1개만 쓴다.
- 한 글에서 형광펜 표시는 3~5개, 핵심 표시는 2~3개, 주의 표시는 1~2개, 면책 표시는 1개를 넘지 않는다.

이미지 자리:

- 이미지는 사람이 직접 넣는다. 실제 이미지를 넣지 말고 자리만 표시한다.
- 자리는 3~5개. 첫 자리는 H1 바로 다음, 요약 문단보다 앞에 둔다. 나머지는 서로 다른 H2 바로 아래에 둔다.
- 아래 네 줄을 빈 줄 없이 연속으로 쓴다. 라벨과 순서를 바꾸지 않는다.

::이미지::
설명: 어떤 그림인지 한국어 한 줄
프롬프트: 영어 이미지 생성 프롬프트 한 줄
::이미지끝::

- 프롬프트는 영어로 쓰고 끝에 항상 `no text, no logo, 16:9`를 붙인다.
- 사람 얼굴이 크게 나오는 구도는 피하고 사물, 서류, 손, 실내, 풍경 위주로 쓴다.
- 실제 브랜드명과 실존 인물 이름을 이미지 프롬프트에 쓰지 않는다.

계산식:

- 계산식이나 공식은 줄 맨 앞에 `>`를 붙여 한 줄 인용으로 쓴다. 여러 줄로 나누지 않는다.
- 곱하기는 `×`, 나누기는 `÷` 기호를 그대로 쓴다.

체크리스트:

- 체크리스트를 넣을 때는 H3 제목에 반드시 "체크리스트"를 넣는다.
- H3 바로 다음에 일반 `-` 목록을 4~6개 쓴다. 사이에 다른 문단을 넣지 않는다.

자주 묻는 질문:

- `Q. 질문` 줄 바로 다음에 `A. 답변` 줄을 빈 줄 없이 붙인다.
- Q/A 쌍은 5~6개 쓴다. 쌍과 쌍 사이에만 빈 줄을 넣는다.
- 질문과 답변에는 `-` 목록이나 표를 넣지 않는다. 각각 한 문단으로 쓴다.

금지:

- LaTeX 수식 표기를 쓰지 않는다. $, \text{}, \times, \frac{} 등을 쓰지 않는다.
- 백틱 3개 코드블록을 쓰지 않는다. 도표가 필요하면 마크다운 표로 쓴다.
- "- [ ]" 체크박스 문법을 쓰지 않는다. 체크리스트는 일반 "-" 목록으로 쓴다.
- Markdown 이미지 문법 ![...](...) 을 쓰지 않는다.
- 목록을 들여쓰지 않는다. 모든 "-" 와 "1." 은 줄 맨 앞에서 시작한다. 중첩 목록을 만들지 않는다.
- your-blog-url 같은 임시 링크
- 임의 URL
- 광고 클릭 유도
- 얕은 양산형 문장
