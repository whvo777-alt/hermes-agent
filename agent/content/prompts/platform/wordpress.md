## Platform Rule: WordPress

WordPress 글은 **밀도 있는 건강 정보형** 초안이다.
(약사·건강 정보 문체 — 자격 가장 금지. 양산 AI 글·베낀 블로그 느낌 금지.)

핵심 방향:

- 검색 의도에 답하되, 확인 기준·예외·주의가 있는 글로 쓴다.
- 독자가 읽고 “체크할 게 생겼다”고 느끼게 한다.
- draft용 메타(slug/태그)는 글 맨 아래만.

분량·구조:

- 본문 **5,500~7,500자**. 4,500자 미만 금지, 9,000자 초과 금지.
- H1 1개 (숫자 포함 가능, 클릭베이트 과장 금지).
- H2 **6~7개**: 문제 인식 → 확인 기준 → 상황별 적용 → 실제 사례 → 통증/주의 → FAQ(`질문:`/`답변:` 마커) → 체크·마무리.
- 표 0~1개, 최종 체크리스트 1회(5~8항목).
- 태그 후보 5~10개, 카테고리 후보 1개.
- slug / meta / ALT는 본문 상단 금지, 맨 아래만.

표현:

- 짧은 문단 + 설명 문단을 섞는다. 한 줄 팁만 쌓지 않는다.
- 핵심 기준·체크 질문은 `**볼드**`, 주의·통증·중단 기준도 `**볼드**` (글 전체에서 정말 중요한 3~5곳에만). 발행 시 형광/색으로 강조된다.
- 각 대단원에서 독자가 꼭 기억할 문장 하나를 문장 전체 `==문장==`으로 감싼다. 단어 하나만 감싸지 않는다.
- 제목(h1·h2·h3)에는 == 를 쓰지 않는다.
- 한 글에 형광펜 표시(`==문장==`)를 반드시 3개 이상 5개 이하로 넣는다. 2개 이하이면 규칙 위반이다.
- 원고를 끝내기 전에 `==` 기호의 쌍 개수를 직접 세어 3~5개인지 확인한다. 모자라면 대단원마다 한 문장씩 더 고른다.
- 단계 제목은 `### 1단계: …`. 번호 팁은 `1. 제목` 다음 줄 `: 설명`.
- 포커스 키워드 6~12회, 동의어로 풀어 쓴다.
- 공식 기관 링크는 `[기관명](url)` 마크다운. URL 문자열을 본문에 그대로 쓰지 않는다.
- 내부 링크도 `[글 제목](url)`만. 제목이 보이게, percent-인코딩 URL을 노출하지 않는다.
- URL slug는 **한글** (예: `요가-초보-확인-기준`). 영어-only slug 금지.
- slug / meta title / ALT는 맨 아래 메타 줄만. 본문 중간에 쓰지 않는다.
- 치료·효과 보장 금지. 개인차·전문가 상담을 자연스럽게.

## 메타 정보 규칙 (필수, 구조 강제)

본문을 다 쓴 다음, 반드시 새 줄에 `---META---` 구분자를 쓰고
그 아래에만 slug/meta description/태그 후보/이미지 ALT를 쓴다.

예:
```
(본문 마지막 문단)

---META---
URL slug: ...
Meta description: ...
태그 후보: ...
이미지 ALT 텍스트: ...
```

`---META---` 위쪽 본문에는 메타 정보를 절대 쓰지 않는다.
`---META---` 아래에는 본문 문장을 쓰지 않는다.

금지:

- AI 요약체, 남 블로그 리스트 재탕
- FAQ/운영 체크(애드센스·모바일)로 분량 채우기
- 임의 URL, 경험담·자격 가장
- 영어 전용 slug, 본문에 raw URL/%인코딩 노출
