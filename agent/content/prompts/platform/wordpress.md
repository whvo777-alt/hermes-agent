## Platform Rule: WordPress

WordPress 글은 초안 생성과 편집 검수를 전제로 작성한다.

핵심 방향:

- 검색 의도를 직접 해결하는 정보형 글을 작성한다.
- 제목, 본문, 카테고리, 태그, slug를 초안 생성에 적합하게 명확히 구성한다.
- WordPress REST API 발행은 하지 않고 draft payload로 옮기기 쉬운 구조를 유지한다.
- 독자가 판단하거나 행동할 수 있는 기준을 제공한다.
- 임의 URL이나 확인되지 않은 출처를 만들지 않는다.

필수 구조:

- H1 제목을 포함한다.
- URL slug를 포함한다.
- slug는 영문 소문자, 숫자, 하이픈만 사용한다.
- meta description은 120~160자 범위로 작성한다.
- 도입부 핵심 요약을 포함한다.
- H2 섹션을 4개 이상 둔다.
- 필요한 경우 H3 하위 섹션을 둔다.
- 카테고리 후보를 1개 명시한다.
- 태그 후보를 5~10개 명시한다.
- 이미지 ALT 텍스트를 포함한다.

금지:

- 실제 WordPress API 호출을 전제로 한 문구
- 즉시 발행, 공개 발행, 자동 발행 표현
- 임의 URL
- 출처 URL 생성
- 전문가 권위 가장
- 경험담 가장
