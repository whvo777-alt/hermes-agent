## Platform Rule: Blogspot

블로그스팟 글은 Google SEO를 지키되 **밀도 있는 자기계발 실전 가이드**로 쓴다.
(실행 톤 — 자격 가장 금지. 양산 AI·동기부여 복붙·남 글 베낀 느낌 금지.)

핵심 방향:

- 검색 의도에 답하고, 읽고 나서 무엇을 해볼지 알 수 있게 쓴다.
- 멋진 문장보다 **검증 가능한 목표/루틴 문장**을 예시로 보여 준다.
- 대표 이미지는 카드형으로 넣되, 본문에 “발행용 이미지” 캡션을 쓰지 않는다.

분량·구조:

- 본문 **5,500~7,500자**. 4,500자 미만 금지, 9,000자 초과 금지.
- H1 1개 (숫자 포함 가능).
- H2 개수는 내용에 따라 정한다. 개수를 맞추려고 필요 없는 절을 만들지 않는다. 본문 흐름은 매거진 스타일 규칙의 다섯 가지 중 이 글 주제에 맞는 하나를 고른다.
- 자주 묻는 질문을 넣을 때는 "질문: ..." 다음 줄에 "답변: ..." 형식으로 쓴다. 각 답변은 2문장에서 4문장.
- 표와 체크리스트는 정말 필요할 때만 넣는다. 둘 다 없는 글이 있어도 된다. 넣는다면 표 1개, 체크리스트 5개에서 8개.
- 자주 묻는 질문 절을 기본으로 쓰지 않는다. 본문 안에서 답하기 어려운 짧은 질문이 정말로 있을 때만 예외로 넣고, 그때도 2개를 넘기지 않는다. 넣을 이유를 한 문장으로 스스로 대지 못하면 절 전체를 뺀다.
- slug / meta / 태그 / ALT는 맨 아래만.

표현:

- 사람 호흡: 상황 묘사 + 기준 + 고친 예시.
- 흔한 “성공하는 습관 N가지” 재배열 금지.
- 【강조 필수】 `**볼드**` 글 전체 3~5곳에만, `### n단계`, `1. 제목` + `: 설명` 팁. 단조 본문 금지.
- 형광펜 표시는 글 전체에 딱 2개만 넣는다. 3개 이상이면 규칙 위반이다.
- 두 개는 서로 다른 대단원에 하나씩 둔다. 그 대단원에서 독자가 꼭 기억해야 할 결론 문장을 고른다.
- 대단원마다 하나씩 넣지 않는다. 모든 절을 정리 문장으로 닫으면 틀에 박힌 글이 된다. 강조 없이 그냥 끝나는 대단원이 더 많아야 자연스럽다.
- 단어 하나만 감싸지 않고 문단 전체도 감싸지 않는다. 마침표까지 포함한 한 문장이다.
- 제목(h1·h2·h3)과 표 안에는 형광펜 표시를 쓰지 않는다.
- 제목(h1·h2·h3)에는 == 를 쓰지 않는다.
- 포커스 키워드 6~12회.
- 외부 링크 0~1개. 개인차 안내 포함.
- 대표 이미지에 “블로그스팟” 등 플랫폼명을 쓰지 않는다.

## 메타 정보 규칙 (필수, 구조 강제)

본문을 다 쓴 다음, 반드시 새 줄에 `---META---` 구분자를 쓰고
그 아래에만 slug/meta description/태그 후보/이미지 ALT를 쓴다.

예:
```
(본문 마지막 문단)

---META---
URL slug: ...
Meta description: ...
태그 후보: ...
이미지 ALT 텍스트: ...
```

`---META---` 위쪽 본문에는 메타 정보를 절대 쓰지 않는다.
`---META---` 아래에는 본문 문장을 쓰지 않는다.

금지:

- [애드센스 승인 체크], [모바일 최적화 체크]
- 본문 상단 메타 노출, 발행용 캡션
- 성공·합격·수익 보장, 전문가 권위 가장
- 속이 빈 짧은 섹션으로만 채우기
- 형광펜/볼드 없이 회색빛 본문만 나열
