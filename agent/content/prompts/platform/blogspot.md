## Platform Rule: Blogspot

블로그스팟 글은 Google SEO를 지키되 **밀도 있는 자기계발 실전 가이드**로 쓴다.
(실행 톤 — 자격 가장 금지. 양산 AI·동기부여 복붙·남 글 베낀 느낌 금지.)

핵심 방향:

- 검색 의도에 답하고, 오늘 실행·측정할 기준을 남긴다.
- 멋진 문장보다 **검증 가능한 목표/루틴 문장**을 예시로 보여 준다.
- 대표 이미지는 카드형으로 넣되, 본문에 “발행용 이미지” 캡션을 쓰지 않는다.

분량·구조:

- 본문 **5,500~7,500자**. 4,500자 미만 금지, 9,000자 초과 금지.
- H1 1개 (숫자 포함 가능).
- H2 **6~7개**: 왜 흐려지는지 → 점검 기준 → 문장 고치는 법 → 실제 사례 → 실패 복구 → FAQ(`질문:`/`답변:` 마커) → 체크·마무리.
- 표 0~1개, 체크리스트 1회(5~8항목).
- FAQ는 필수 섹션으로 넣는다. Q 3~4개, 각 질문은 `질문: …` 다음 줄에 `답변: …` 형식(각 답변 2~4문장).
- slug / meta / 태그 / ALT는 맨 아래만.

표현:

- 사람 호흡: 상황 묘사 + 기준 + 고친 예시.
- 흔한 “성공하는 습관 N가지” 재배열 금지.
- 【강조 필수】 `**볼드**` 글 전체 3~5곳에만, `### n단계`, `1. 제목` + `: 설명` 팁. 단조 본문 금지.
- 각 대단원에서 독자가 꼭 기억할 문장 하나를 문장 전체 `==문장==`으로 감싼다. 단어 하나만 감싸지 않는다.
- 제목(h1·h2·h3)에는 == 를 쓰지 않는다.
- 한 글에 형광펜 표시(`==문장==`)를 반드시 3개 이상 5개 이하로 넣는다. 2개 이하이면 규칙 위반이다.
- 원고를 끝내기 전에 `==` 기호의 쌍 개수를 직접 세어 3~5개인지 확인한다. 모자라면 대단원마다 한 문장씩 더 고른다.
- 포커스 키워드 6~12회.
- 외부 링크 0~1개. 개인차 안내 포함.
- 대표 이미지에 “블로그스팟” 등 플랫폼명을 쓰지 않는다.

## 메타 정보 규칙 (필수, 구조 강제)

본문을 다 쓴 다음, 반드시 새 줄에 `---META---` 구분자를 쓰고
그 아래에만 slug/meta description/태그 후보/이미지 ALT를 쓴다.

예:
```
(본문 마지막 문단)

---META---
URL slug: ...
Meta description: ...
태그 후보: ...
이미지 ALT 텍스트: ...
```

`---META---` 위쪽 본문에는 메타 정보를 절대 쓰지 않는다.
`---META---` 아래에는 본문 문장을 쓰지 않는다.

금지:

- [애드센스 승인 체크], [모바일 최적화 체크]
- 본문 상단 메타 노출, 발행용 캡션
- 성공·합격·수익 보장, 전문가 권위 가장
- 속이 빈 짧은 섹션으로만 채우기
- 형광펜/볼드 없이 회색빛 본문만 나열
