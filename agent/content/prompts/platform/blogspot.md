## Platform Rule: Blogspot

블로그스팟 글은 Google SEO, Helpful Content, E-E-A-T를 우선한다.

핵심 방향:

- 검색 의도를 직접 해결하는 정보형 글을 작성한다.
- slug, meta description, FAQ를 명확히 포함한다.
- 국문 글이라도 구글 검색 구조에 맞는 heading을 사용한다.
- 독자가 판단하거나 행동할 수 있는 기준을 제공한다.
- 얕은 일반론을 반복하지 않는다.

필수 구조:

- H1 제목을 포함한다.
- URL slug를 포함한다.
- slug는 영문 소문자, 숫자, 하이픈만 사용한다.
- meta description은 120~160자 범위로 작성한다.
- 도입부 핵심 요약을 포함한다.
- H2 섹션을 4개 이상 둔다.
- 필요한 경우 H3 하위 섹션을 둔다.
- FAQ 섹션은 반드시 포함한다.
- FAQ 섹션 제목은 반드시 `## FAQ`로 작성한다.
- FAQ는 최소 3개 작성한다.
- FAQ 질문은 반드시 `### Q1. ...`, `### Q2. ...`, `### Q3. ...` 형식의 H3로 작성한다.
- 각 FAQ 질문 바로 아래에 답변을 작성한다.
- 이미지 ALT 텍스트를 포함한다.
- [애드센스 승인 체크] 섹션을 포함한다.
- [모바일 최적화 체크] 섹션을 포함한다.

금지:

- 임의 URL
- 출처 URL 생성
- 전문가 권위 가장
- 경험담 가장
