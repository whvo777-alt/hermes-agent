## Anti-AI Pattern Rule

AI가 쓴 글·양산형 블로그처럼 보이는 문체를 피한다.
다른 사람 글을 베낀 듯한 구성도 피한다.

절대 피하기:

- 누구에게나 통하는 추상 조언만 나열 (“꾸준히 하세요”, “계획이 중요합니다”)
- “중요합니다/필수입니다/결론적으로/결국” 반복
- 같은 결론을 다른 말로 3번 이상 반복
- 근거 없는 “최고/완벽/무조건/반드시 효과”
- 경험 없는 1인칭 후기 (“제가 직접 써보니”, “솔직히 말할게요”)
- 검색 키워드를 부자연스럽게 반복
- 문단마다 같은 리듬 (질문→답→팁 기계 반복)
- 인터넷에 흔한 “N가지 방법”을 그대로 재배열한 느낌
- “요즘 핫한”, “많은 사람들이”, “전문가들은 말합니다”처럼 출처 없는 권위 문구
- 목차만 있고 속이 빈 섹션 (제목만 다르고 내용 동일)
- **모든 단락 끝마다 굵은 결론 문장을 다는 습관** — 강조 없이 그냥 끝나는 단락이 더 많아야 자연스럽다
- 매 글 구조를 판박이로 맞추는 것 (예: 항상 5단계 + 표 1개 + 체크리스트 8개로 딱 떨어짐)
- 본문에서 글 쓰는 의도·타겟 독자·작성 목적을 설명하는 문장
  (“독자가 ~하도록 정리했습니다”, “타겟 독자를 위해 ~했습니다” 같은 문장은 본문이 아니라 내부 지침이 새어나온 것)

대신 이렇게:

- 독자가 **바로 점검할 질문**을 제시한다
- 상황별 차이(시간/체력/예산/통증/업무량)를 구체적으로 적는다
- 대비(나쁜 선택 vs 나은 선택)를 보여줄 때 “나쁜 예 → 고친 예” 화살표 문장으로만 쓰지 않는다.
  글마다 다른 방식을 고른다: 질문형(“이렇게 하고 있진 않나요?”), 일화형(짧은 상황 묘사 한두 문장),
  서술형(대비를 화살표 없이 한 문단 흐름 속에 녹이기) 등을 섞어 쓴다.
- 실패했을 때 보이는 신호와 복구 기준을 적는다
- 모르는 정보는 모른다고 하고 확인 필요성을 밝힌다
- 직접 경험이 없으면 선택 기준·주의점·비교 포인트로 쓴다
- 문장 길이와 문단 구조를 섞어 사람이 쓴 호흡을 만든다
- 강조(볼드)는 글 전체에서 정말 중요한 곳에만 띄엄띄엄 넣는다 — 규칙적으로(단락마다, 목록마다) 넣지 않는다
- 글 구조(단계 개수, 표·체크리스트 유무, 번호 목록 여부)를 매번 다르게 가져간다 — 필요 없으면 표나
  체크리스트를 아예 안 써도 된다
- 가벼운 개인적 어투, 짧은 반문, 뉘앙스 있는 의견(단정이 아닌 “~인 것 같다/~일 수도 있다” 식)을
  가끔 섞어 사람이 쓴 느낌을 낸다 — 단, 카테고리별 안전장치(과장 금지, 전문가 상담 권장 등)는 그대로 지킨다

말꼬리를 돌려쓰지 않는다

한 글에서 "~할 수 있습니다"를 열 번 넘게 쓰지 않는다. 실제로 세어 보니
한 편에 열두 번에서 스물여섯 번까지 나왔다. 일곱 줄에 한 번꼴이면
읽는 사람이 기계가 쓴 글이라고 느낀다.

문장 끝을 서너 가지로 돌리지 않는다. 지금 한 편에서 "있습니다 · 합니다 ·
어렵습니다" 셋이 전체 문장의 60%를 차지한다.

이렇게 쓰지 않는다 (한 문단에 "수 있습니다"가 세 번):
  체수분이 낮으면 근육량이 적을 수 있습니다. 짠 음식을 먹으면 일시적으로
  늘 수 있습니다. 측정 시간에 따라 값이 달라질 수 있습니다.

이렇게 쓴다 (내용은 같고 말꼬리만 바꿈):
  체수분이 낮으면 근육량이 적은 경우가 많습니다. 짠 음식을 먹은 다음 날은
  일시적으로 늘기도 합니다. 측정 시간에 따라서도 값이 달라집니다.

바꿔 쓸 수 있는 말:
  ~하는 경우가 많습니다 · ~하기도 합니다 · ~인 편입니다 · ~로 보입니다
  ~하면 도움이 됩니다 · ~에 가깝습니다 · ~로 나뉩니다 · ~부터 봅니다

단정을 피하는 것은 그대로 지킨다. 뜻을 바꾸지 말고 말꼬리만 바꾼다.
병을 단정하거나 효과를 장담하는 문장으로 바꾸지 않는다.

"A가 아니라 B입니다"를 한 글에서 세 번 넘게 쓰지 않는다. 대비를 보일 때는
질문형, 짧은 상황 묘사, 한 문단 안의 흐름 가운데 매번 다른 방식을 고른다.

문장 길이를 섞는다. 긴 문장이 세 번 이어지면 짧은 문장을 하나 넣는다.
모든 문장이 "-습니다"로 끝나지 않아도 된다. 명사로 끝나는 문장이나
짧은 반문을 글마다 한두 번 섞는다.

위 본보기는 모양을 보여주는 것일 뿐이다. 내용을 가져다 쓰지 않는다.
