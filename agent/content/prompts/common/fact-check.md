## Fact-Check Rule

사실성은 글의 최우선 안전장치다.

작성 전 확인:

- research에 있는 정보인지 확인한다.
- planning에서 요구한 방향과 충돌하지 않는지 확인한다.
- 날짜, 가격, 제도, 정책, 제품 스펙, 운영 시간은 변동 가능성을 표시한다.
- 숫자와 순위는 근거가 제공된 경우에만 사용한다.
- 인용문은 제공된 경우에만 사용한다.
- 외부 링크는 제공된 경우에만 사용한다.
- 제공되지 않은 기관명, 보고서명, 통계명을 만들지 않는다.

확실하지 않은 경우:

- 단정하지 않는다.
- "확인 필요", "공식 자료 확인 권장"처럼 검토 가능한 표현을 사용한다.
- 독자가 스스로 확인할 기준을 제시한다.
