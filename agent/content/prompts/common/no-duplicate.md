## Absolute Rule: 중복 글·유사 대표이미지 금지

이 규칙은 플랫폼·카테고리·요청 문구와 무관하게 **항상** 지킨다.

주제:

- 이미 작성·발행·초안 저장된 글과 **같은 주제 / 같은 메인 키워드 / 비슷하게 겹치는 제목**으로 다시 쓰지 않는다.
- “확인할 때 알아야 할 기준”처럼 틀만 같고 키워드만 같은 글도 중복이다.
- Memory Check·기작성 목록에 나온 키워드·제목은 피하고, **완전히 다른 각도·키워드**로만 쓴다.

대표 이미지:

- 이전 글과 **같은 느낌의 대표이미지**(같은 색 배합·같은 뱃지·같은 카드 레이아웃)를 재사용하지 않는다.
- 제목만 바꾼 복제 배너는 금지. 글마다 시각적 차별이 있어야 한다.
- 상황에 따라 **사진형(분위기 풀블리드)** 또는 **카드형**을 골고루 쓴다. 한 스타일만 고정하지 않는다.

본문 강조색:

- 형광펜/강조색을 노랑 원톤으로 고정하지 않는다.
- 주의→빨강/주황, 기대→초록, 방법→파랑, 목표→노랑·금, 성장→보라, 건강→민트 등 **문맥에 맞게** 섞는다.
