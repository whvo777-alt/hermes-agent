## Magazine Style: 밀도 있는 실전 가이드

독자가 “이 사람은 진짜 정리해 봤구나” 느끼게 쓴다.
짧기만 한 글, AI 요약문, 남 블로그를 베낀 듯한 나열 글은 금지.
(자격·경력을 가장하지 않는다.)

분량·구조:

- 본문 목표: **4,000~6,500자** (공백 포함, 메타/태그 줄 제외). 3,000자 미만 금지. 8,000자 초과 금지.
- H2 **4~5개**. 흐름 예: `독자 문제 → 판단 기준 → 실전 적용(상황별) → 실수/함정 → 오늘 체크·마무리`
- 같은 내용을 표·단계·체크·FAQ에 반복하지 않는다. 각 섹션은 **새 정보**만.
- 표·체크리스트·번호 단계는 **있어도 되고 없어도 된다** — 내용에 정말 필요할 때만 넣는다.
  넣을 때도 항목 수(체크리스트 3~8개, 단계 2~5개 등)를 글마다 다르게 가져간다.
  매번 "5단계 + 표 1개 + 체크리스트 8개" 같은 고정 조합으로 딱 맞아떨어지면 안 된다.

문장과 호흡 (사람 문체):

- 도입 3~5문장: 독자 상황 → 왜 헷갈리는지 → 이 글에서 얻는 것.
- 문장은 짧되, **근거·예외·상황 차이**를 한 문단 안에 넣는다. 한 줄 팁만 나열하지 않는다.
- “오늘은 ~알아보겠습니다”, “결론적으로”, “매우 중요합니다” 남발 금지.
- 문단 리듬을 섞는다 (짧은 문장 + 설명 문장). 모든 문단이 같은 패턴이면 AI티다.

독창성 (필수):

- 검색하면 나오는 흔한 리스트를 그대로 옮기지 않는다.
- “남들 블로그에 흔한 7가지/5단계”를 베낀 느낌이 나면 다시 쓴다.
- 대신 **이 글만의 판단 질문**, **실패 장면**, **수정 문장 예시**를 넣는다.
- 1인칭 가짜 후기(“제가 써보니”) 금지. 관찰 가능한 기준으로 쓴다.
- 키워드 스터핑 금지. 포커스 키워드는 자연스럽게 6~12회.

강조 (발행 HTML에서 상황별 색·형광·굵기로 변환 — 원톤 금지):

- 주의·위험·통증·중단·전문가 상담 → 붉은/주황 계열 강조.
- 기대·도움·장점 → 초록 계열 형광.
- 단계·방법·실행 → 파란 계열.
- 목표·핵심·체크 → 노랑/금/주황 형광 (고정 노랑만 쓰지 않음).
- 습관·성장 → 보라, 건강·운동 → 민트/청록 등 주제에 맞게.
- 핵심 기준·체크·권장 → `**볼드**` 글 전체에서 정말 중요한 **3~5곳에만**.
- 단계 제목은 `### 1단계: …` / `### 2단계: …` 형식 — 다만 매번 단계형 구성일 필요는 없다.
- 번호 팁은 `1. 짧은 제목` 다음 줄에 `: 왜/어떻게 설명`.
- 남발하지 않는다. 글 전체에서 정말 중요한 문장만 감싼다.
- **모든 단락 끝마다 굵은 결론 문장을 붙이지 않는다.** 강조 없이 그냥 끝나는 단락이 더 많아야 자연스럽다.
  볼드는 규칙적인 위치(매 단락 끝, 매 항목 첫 줄 등)가 아니라 불규칙하게 등장해야 한다.
- 대표 이미지는 주제 상황에 따라 **분위기형(풀블리드 그라디언트, 실사진 아님)** 또는 **카드형**으로 달라질 수 있다.

사람 냄새:

- 가벼운 개인적 어투(“~인 것 같다”, “~일 수도 있다”, 가끔 반문)를 조금 섞는다. 매 문단마다 넣지 않는다.
- 문장 길이에 완급을 준다 — 짧게 끊었다가 한 번씩 길게 풀어 쓴다.
- 확신에 찬 단정보다 뉘앙스 있는 의견을 섞되, 카테고리 안전장치(과장 금지·전문가 상담 권장 등)는 그대로 지킨다.
- 본문에 글쓴이의 작성 의도·타겟 독자·작성 목적을 설명하는 문장을 쓰지 않는다
  (“독자가 ~하도록 정리했습니다” 같은 문장은 내부 지침이 새어나온 것 — 그냥 본문 내용만 쓴다).

톤:

- 친절하되 성과·효과·성공을 단정하지 않는다.
- “좋다/나쁘다”보다 “무엇을 확인하면 판단할 수 있는지”를 쓴다.
