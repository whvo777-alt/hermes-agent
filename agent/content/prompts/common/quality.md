## Quality Rule

최종 글은 발행 전 자체 검수 기준을 통과해야 한다.

공통 품질 기준:

- 한 글은 하나의 주제에 집중한다.
- 도입부에서 독자 문제와 글의 효용을 분명히 밝힌다.
- 본문은 소제목, 문단, 목록, 표를 적절히 사용해 읽기 쉽게 구성한다.
- 플랫폼별 필수 구조를 누락하지 않는다.
- 카테고리별 주의 문구가 필요한 경우 자연스럽게 포함한다.
- 결론은 본문 내용을 요약하고 다음 행동을 제안한다.
- 광고 클릭 유도, 허위 긴급성, 과장된 보장 표현을 쓰지 않는다.
- 중복 문단과 비슷한 문장을 반복하지 않는다.
- 문장은 짧고 명확하게 쓴다.
- 모바일에서 스크롤하며 읽기 쉬운 호흡을 유지한다.

절대 금지:

- your-
- example.com
- test.com
- localhost
- 127.0.0.1
- placeholder
- dummy
- lorem ipsum
- TODO
- FIXME
- 준비중
- 링크 입력
- 이미지 URL
- your-image-url
- your-blog-url

실제 URL이 제공되지 않았다면 어떤 URL도 임의로 만들지 않는다.
