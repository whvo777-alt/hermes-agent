## Quality Rule

최종 글은 발행 전 자체 검수 기준을 통과해야 한다.

공통 품질 기준:

- 한 글은 하나의 주제에 집중한다.
- WordPress/Blogspot: 본문 **5,500~7,500자**, H2 **6~7개**, 속이 찬 실전 가이드(실전 사례·FAQ 섹션 포함).
- 도입에서 독자 문제와 효용을 분명히 밝힌다.
- 본문은 소제목·구체 예시·(필요 시) 표로 읽기 쉽게.
- AI 요약체·양산 블로그 리스트 재탕·가짜 후기를 쓰지 않는다.
- 같은 내용을 표·단계·체크·FAQ에 반복하지 않는다.
- 핵심 기준·주의·체크 질문은 `**볼드**` (글 전체에서 정말 중요한 3~5곳에만; 발행 시 형광/색 강조).
- URL slug는 한글. 영어-only slug·본문 raw URL 노출 금지.
- 광고 클릭 유도, 허위 긴급성, 과장 보장 금지.
- 문장은 짧고 명확하되, 근거·예외가 있어야 한다.

절대 금지:

- your-
- example.com
- test.com
- localhost
- 127.0.0.1
- placeholder
- dummy
- lorem ipsum
- TODO
- FIXME
- 준비중
- 링크 입력
- 이미지 URL
- your-image-url
- your-blog-url

실제 URL이 제공되지 않았다면 어떤 URL도 임의로 만들지 않는다.
